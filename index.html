How it is wired

  1. Your message goes to the code-assistant Supabase Edge Function.
  2. The function prepends a coding system prompt and forwards the chat to the model.
  3. Tokens stream back token-by-token over SSE.
  4. Messages are persisted in your Supabase project (ai_conversations / ai_messages).

Upgrade to the real weights (optional)

By default the app uses a free, anonymous text API so it works instantly. To run the genuine Qwen2.5-Coder-1.5B-Instruct weights, create a free Hugging Face token, then in Supabase go to Edge Functions → Secrets and add HF_TOKEN = your token (optionally AI_MODEL). Redeploy happens automatically — no code change.
