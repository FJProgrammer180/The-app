ATLAS OS

FROM INTENT TO VERIFIED EXECUTION

Give ATLAS a goal. It plans, runs only registered backend tools under a server-side policy engine, pauses for your approval on consequential actions, verifies every result — and shows you the evidence.

Autonomous workflow

INTENT→PLAN→POLICY CHECK→TOOL EXECUTION→APPROVAL (RISK 2)→VERIFICATION→ARTIFACT

🔐 Human approval

Risk-2 actions (email, deletion, external writes) pause before executing. Approvals are bound to the exact argument hash, expire in 15 minutes, and are single-use.

🧰 Tool registry

Only typed, registered backend tools can run — no shell, no arbitrary code. Every call is schema-validated, persisted, and verified by read-after-write.

📜 Live evidence

Execution events stream from the backend over SSE and survive refresh. Nothing is marked done until the persisted record proves it.
